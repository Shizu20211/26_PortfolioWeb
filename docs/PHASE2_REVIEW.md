# Phase 2 圖片基礎審核紀錄

審核日期：2026-09-11

## 審核結果

第二階段「圖片基礎」保留通過。共用 Responsive Picture、載入優先級、固定尺寸、
三語 Alt 與 `currentSrc` 介面可作為後續開發基線。

## 必須回頭複審

目前通過的是圖片元件與資料介面，不代表正式視覺素材已核准。待 Featured、Projects、
Artworks、Hero 分層插畫或其他正式圖片加入後，必須回到本階段重新檢查：

- AVIF、WebP 與原始格式 fallback 是否指向實際檔案。
- `srcset`、`sizes` 是否符合桌面、手機橫向及手機直向版面。
- 圖片實際寬高、比例與裁切是否正確，且沒有 Layout Shift。
- 中文、英文、日文 Alt 是否準確描述已核准的素材。
- Hero／首屏圖片載入優先級，以及其他作品圖片的 Lazy Loading 是否正確。
- 後續圖片轉場是否讀取瀏覽器實際選用的 `currentSrc`。
- 圖片使用權、公開範圍與預定用途是否已由使用者確認。

在以上項目複審完成前，不得把 Placeholder 或尚未核准的圖片視為最終交付素材。
