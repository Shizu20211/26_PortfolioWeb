# Phase 4 Featured Horizontal Gallery 重新檢核

更新日期：2026-09-16

## 基線說明

原 Phase 4 已審核通過，既有 `v0.4.0-phase4` Tag 保留為當時正式基線。本次屬於後續響應式修正，使用者重新確認前不移動既有 Tag。

## 本次修正範圍

- Featured 兩個細節頁改用同一份共用 Subpanel Heading。
- Subpanel Heading 從第一個細節頁開始出現，並在 Featured 細節區間固定於英文姓名下方。
- 橫向低高度版面適用範圍調整為最大 1180 × 720。
- 重新分配互動細節頁的圖片與文字比例。
- 低高度畫面的文字欄可獨立垂直捲動，避免 Metadata 與連結被底部導覽遮住。
- Featured 標題與細節標題最多兩行，字級依所在內容區域調整並採平衡斷句。
- Section 邊界雲朵移至全域裝飾層，避免水平切換時被裁成半張。

## 程式檢核矩陣

| 項目               | PC 一般畫面  | PC 低高度／手機橫向 | 手機直向            |
| ------------------ | ------------ | ------------------- | ------------------- |
| Overview 主標      | 最多兩行     | 最多兩行            | 最多兩行            |
| 共用小標位置       | 英文姓名下方 | 英文姓名下方        | 細節內容上方 Sticky |
| Visual 細節頁      | 圖文雙欄     | 緊湊雙欄            | 單欄                |
| Interaction 細節頁 | 圖文雙欄     | 重分欄、文字可捲動  | 單欄                |
| 圖片與底部導覽     | 保留安全距離 | 限制圖片高度        | 內容自然增高        |
| Reduced Motion     | 保留         | 保留                | 保留                |

## 待畫面驗收

- 三種語言切換後，小標與細節標題不得遮住 Header、圖片或正文。
- Featured 第二、第三面板切換時，共用小標不得重複、跳位或消失。
- 低高度橫向畫面中，Interaction 的 Metadata 與「查看專案」連結必須可讀取。
- 正式瀏覽器視覺檢核通過後，才決定是否建立新的修正版 Tag。

## 後續備註

Water Effect 待 Featured 正式背景完成後再加入，避免更換背景後重新調整整套水波參數。後續實作仍須遵守 Reduced Motion、文字可讀性與行動裝置效能限制。
