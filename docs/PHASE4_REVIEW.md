# Phase 4 Featured Horizontal Gallery 重新檢核

更新日期：2026-09-16

## 基線說明

原 Phase 4 基線 `v0.4.0-phase4` 保留；本次響應式修正已於 2026-09-16 通過，新增正式基線 `v0.4.1-phase4`。

## 本次修正範圍

- Featured 兩個細節頁改用同一份共用 Subpanel Heading。
- Subpanel Heading 改為單行 `01 · 精選專案`，從第一個細節頁開始出現，在 Featured 細節區間固定於英文姓名下方，並於 Projects 前提早淡出。
- 橫向低高度版面適用範圍調整為最大 1180 × 720。
- 重新分配互動細節頁的圖片與文字比例。
- 低高度畫面縮小標題、正文與 Metadata 間距，不使用細節文字欄內部捲軸。
- Overview 保留原本大型 H2；本次只調整第二、第三面板的共用懸浮小標。標題顯示完整文字並採平衡斷句，不使用裁切。
- Section 邊界雲朵移至全域裝飾層，避免水平切換時被裁成半張。
